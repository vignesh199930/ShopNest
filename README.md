# ShopNest 🛒

A Full Stack E-Commerce Web Application built using React.js and Spring Boot.

## Tech Stack
- React.js
- Java
- Spring Boot
- Spring Security (JWT)
- MySQL
- Bootstrap

## Features
- User Login & Registration
- JWT Authentication
- Product Listing
- Product Details
- Search & Filter
- Shopping Cart
- Wishlist
- Checkout
- Order Placement
- My Orders
- User Profile

## How to Run

### Frontend
```bash
npm install
npm start
```

### Backend
Run the Spring Boot application from your IDE.
